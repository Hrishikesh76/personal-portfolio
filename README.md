# Modern Personal Portfolio

A production-ready personal portfolio built with React, Vite, Tailwind CSS, Framer Motion, and Lucide React. It includes light and dark themes, persisted theme preference, responsive navigation, animated sections, project filtering, and a validated contact form.

## Tech Stack

- ReactJS + Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- React Router DOM

## Getting Started

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production Build

```bash
npm run build
npm run preview
```

## Customize

- Portfolio content: `src/data/portfolio.js`
- Theme logic: `src/hooks/useTheme.js`
- Section components: `src/sections`
- Shared UI components: `src/components`

Replace placeholder links, resume URL, and profile/project imagery with your real assets before deployment.
